# Saint-Pierre-et-Miquelon: tax pack

Saint-Pierre-et-Miquelon uses a local income-tax code administered by the territorial fiscal services, in euros. The code provides local personal and corporate income taxes, employer reporting, investment-income withholding, social-contribution deductions, and rules for non-residents. French or EU VAT is not charged in the archipelago; local customs and consumption duties require separate classification.
